# 微信风格通话页设计

## 目标

把 Flutter 通话页改成微信语音通话的视觉结构，同时保留现有 LiveKit 通话逻辑，并修复“Agent 已开口但页面一直等待接听”的状态竞态。

## 布局

- 全屏背景：有 Agent 照片时使用模糊头像铺底并加暗色遮罩；没有照片时使用深色渐变。
- 页面顶部显示“语音通话”。
- 中部：168px 头像区域、Agent 名称、状态文字或通话计时。
- 连接/响铃阶段头像外围显示缓慢脉冲圆环；进入通话后隐藏。
- 底部三个圆形按钮：静音、免提、红色挂断；按钮下方显示简短文字标签。
- 通话结束显示“通话结束”和关闭入口，同时保留原有的 3 秒自动返回。

## 状态与音频

- 监听远端音频轨订阅；即使音频在页面进入响铃状态之前到达，也记录 `_agentAudioReady`，进入响铃后立即激活通话并开始计时。
- Agent 断开时停止计时并进入结束状态，不自动切回响铃。
- 静音通过 `LocalAudioTrack.mute(stopOnMute: false)` / `unmute` 切换，不释放麦克风设备。
- 免提只在移动端启用；Web 端点击时提示由系统控制输出设备。
- 麦克风错误在状态下方显示简短提示，原始异常只通过 SnackBar 展示。

## 不做

- 不做视频通话、最小化悬浮窗、通话录音或新的后端接口。
- 不改变 Agent 选择、Token、LiveKit 连接和 Agent 运行时逻辑。

## 验证

- `flutter build web --base-href /app/` 通过。
- 分别拨打 Pipeline 和端到端 Agent，确认页面能从“等待对方接听”进入计时，静音/挂断可用。
- 部署后需要强制刷新浏览器，避免旧 service worker 继续使用旧构建。
